Advanced Fleet Rental Management
================================

Advanced Fleet Rental Management enhances Odoo's fleet management functionality
for vehicle rental businesses, covering cars, vans, bikes, and other vehicles.

Key Features
------------

* Detailed rental contracts and flexible invoicing.
* Daily, hourly, and kilometer-based rental period management.
* Multiple rental payment plan options (full, daily, weekly, monthly).
* Integration with Odoo Invoicing for automated invoice creation and payment tracking.
* Tracking of vehicle status, maintenance intervals, and damage reports with dedicated invoicing.
* Interactive fleet performance dashboard for real-time monitoring of vehicles and contracts.

Installation
------------

No external dependencies.

Configuration
-------------

No additional configuration is required. Configure vehicle rental terms and cancellation policies directly from the Fleet > Rental menus.
