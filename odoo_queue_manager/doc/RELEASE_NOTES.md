## Module Queue Manager

#### 21.10.2026
#### Version 20.0.1.0.0
#### Features & Bug Fixes
- Initial release for Odoo 20.0 Queue Manager.
- Interactive token generation kiosk and department queue workflows.
- Real-time queue processing and public display screen interfaces.
- Enforced strict authorization checks on queue counter and processing routes.
- Removed public/portal direct model access on token records to safeguard customer contact info.
- Secured token receipt download URLs with unique access tokens (preventing IDOR).
- Corrected counter and calling staff display details in the counter processing view.
