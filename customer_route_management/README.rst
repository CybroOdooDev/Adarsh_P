Customer Route Management
=========================

Organise your customers into delivery routes and areas, set the order in which
they are delivered, and print route reports with their contact details and the
amounts they owe.

Key Features
------------

* Create delivery routes and split each one into areas (route lines).
* Assign each customer to an area from the Sales & Purchase tab of the contact.
* Drag the customers of an area to set their delivery order; reports follow it.
* See what each customer and its contacts owe: the open items of their receivable
  account (unpaid invoices, credit notes, unmatched payments), per company.
  Vendor bills are not included.
* Print a PDF report or download an Excel report, with one sheet per route.
* Show each open item, only the total due, or no amounts at all.
* User and Manager access levels, with routes kept per company.

Installation
------------
No external dependencies. The Excel report uses XlsxWriter, which is installed
with Odoo.

Configuration
-------------
In Settings > Users & Companies > Users, choose User or Manager for Delivery
Route Creation. Users can view routes and print reports; managers can also
create and edit routes. The administrator is a Manager by default.
